## 🚀 البدء السريع

### المتطلبات
- Node.js 16+
- npm أو yarn
- Expo CLI (اختياري)

### التثبيت

```bash
# استنساخ المشروع
git clone <repo-url>
cd mashatl-mobile

# تثبيت المكتبات
npm install

# تشغيل التطبيق
npm start
```

### التشغيل على الأجهزة

```bash
# Android
npm run android

# iOS (يتطلب macOS)
npm run ios

# الويب
npm run web
```

## 🔧 المكتبات المستخدمة

- **React Native**: إطار عمل لتطوير التطبيقات
- **Expo**: منصة لتطوير تطبيقات React Native
- **AsyncStorage**: تخزين البيانات محلياً
- **XLSX**: تصدير البيانات إلى Excel
- **Firebase**: قاعدة البيانات السحابية
- **Expo Notifications**: نظام الإشعارات

## 💾 إدارة البيانات

### التخزين المحلي
تُحفظ جميع البيانات محلياً في `AsyncStorage` للوصول السريع والعمل بدون اتصال.

### التصدير إلى Excel
يمكن تصدير جميع البيانات إلى ملفات Excel بصيغة احترافية.

```typescript
// مثال على التصدير
await exportAll(); // تصدير جميع البيانات
```
